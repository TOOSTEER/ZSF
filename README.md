# Квест — мобильное веб-приложение

Проект состоит из двух независимых частей: `backend/` (Go + PostgreSQL) и
`frontend/` (чистые HTML/CSS/JS, без сборщиков).

## Backend

Требования: Go 1.22+, PostgreSQL 15+.

```bash
cd backend
cp .env.example .env      # поправьте DATABASE_URL / JWT_SECRET при необходимости

# применить миграции (любым удобным способом, например psql):
psql "$DATABASE_URL" -f migrations/001_init.sql
psql "$DATABASE_URL" -f migrations/002_seed.sql

go run ./cmd/server
# сервер поднимется на http://localhost:8080
```

Проверка: `curl http://localhost:8080/health` → `ok`.

> Примечание: в go.mod есть несколько `replace`-директив на GitHub-зеркала
> пакетов `golang.org/x/*` — это официальные read-only зеркала, добавленные
> из-за сетевых ограничений среды сборки. При обычном доступе в интернет
> их можно оставить как есть (модуль уже собран и протестирован с ними,
> `go build ./...` проходит чисто) либо убрать вместе с `go mod tidy`.

## Frontend

Никакой сборки не требуется — это статические файлы.

```bash
cd frontend
python3 -m http.server 5500
# либо любой другой статик-сервер / расширение Live Server
```

Откройте `http://localhost:5500/index.html`. Не открывайте файлы напрямую
через `file://` — `fetch()` к API и относительные пути работают только
через http(s).

Перед запуском проверьте, что `CONFIG.API_URL` в `js/config.js` указывает
на адрес бэкенда (по умолчанию `http://localhost:8080/api`), а `CORS_ORIGIN`
в `.env` бэкенда — на адрес фронтенда (по умолчанию `http://localhost:5500`).
